# Corpus map

The project's rules, captured verbatim from their source (a guide, a spec, a handbook), one file per page in docs/guide/ numbered in the source's own order. CAPTURED = transcribed word for word; PENDING = not yet captured (never guess a pending page's rule).

## Pages
- (source page) -> `guide/00_<slug>.md` : PENDING

## Conventions
- Verbatim text keeps the source's punctuation and typos inside quoted content.
- Notes are italic parentheticals marked "(Corpus note: ...)" so they never pass as source wording.
- Inconsistencies are surfaced in a note, never papered over.
